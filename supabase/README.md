# Supabase no PratoPronto

Esta pasta registra mudanças críticas aplicadas ao projeto Supabase.

As migrations aqui adicionadas documentam deltas aplicados ao banco existente; não constituem, sozinhas, um bootstrap completo de um projeto Supabase vazio.

Antes de qualquer mudança de produção:

1. rode os testes do aplicativo;
2. aplique migrations com revisão;
3. rode Security Advisors e Performance Advisors;
4. teste autenticação e os fluxos críticos com contas de homologação;
5. só então promova a mesma versão para produção.
